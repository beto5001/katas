# Katas em Node.js

Cada kata Node fica em sua própria pasta e inclui o enunciado, a implementação, testes e uma API HTTP simples.

## Executar o Kata 2

```bash
cd node-katas/kata-02-time-conversion
npm test
npm start
```

Enquanto a solução estiver pendente, os testes falharão de propósito. Implemente a função indicada no enunciado e execute os testes novamente.

## Convenções

- `src/`: código da API e da solução do kata.
- `test/`: testes sem dependências externas.
- `README.md`: enunciado, contrato HTTP e como executar.
